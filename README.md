1. Project Title
 Product Sales Analysis using SQL and Power BI

2.Description
This project analyzes Product sales data to identify trends, product performance, regional performance, and factors affecting sales. 
SQL was used for data exploration and analysis, while Power BI was used to create interactive dashboards and visualize insights.

3. Tool used
SQL – Data exploration and analysis  
Power BI – Data visualization and dashboard creation

4. Key Analysis
• Yearly sales trend analysis (2023–2025)
• Region-wise and product-wise sales performance
• Promotion impact on sales
• Customer and salesperson performance
• Previous Month, Previous Quarter, Previous Year comparison
• Root cause analysis of 2025 sales decline using Decomposition Tree
